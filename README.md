# 三三作息簿 · 公开演示

一个用时间轴来安排每一天的作息簿：每天按基础模板自动生成日程，再按当天情况微调，并跟踪学习项目的进度。

在线体验：<https://sihan3333.github.io/sansan-planner-demo/>

> 本仓库是公开演示版。界面和功能与作者自用的最新版一致，但内置的模板、学习项目都是**虚构示例**，与作者本人的生活安排无关。

## 功能

- **今天的日程**：24 小时时间轴，按分类着色；可以前后翻日期、跳到某一天，红线标出当前时间。
  - 支持「时间段」和「时间点」两种活动（比如「出门」就是一个时间点）。
  - 大块活动可以再拆「细分安排」，每一项都能单独打勾。
  - 睡眠时段自动折叠成一条，连续 1 小时以上没有安排的地方标为「空闲」。
  - 时间重叠的活动会用虚线框和 ⚠ 提醒。
- **今日学习**：汇总当天所有学习类活动的完成情况；填了相同「所属大类」的活动（比如「背单词」和「英语听力」都属于「英语」）会合并统计、颜色一致。当天学习全部完成时会放烟花庆祝。
- **基础模板**：编辑一套标准的一天，以后新打开的日期会按模板生成；也可以用模板一键覆盖某一天（会二次确认）。
- **学习项目**：给课程、书、单词等设总量和每日目标，查看进度条和预计还要几天；按大类分组，可以置顶最关心的大类。
- **打勾自动推进度**：日程里的活动可以关联一个学习项目，并设定“完成一次推进多少”。打勾完成后进度自动增加，取消打勾自动扣回；有细分的活动要全部勾完才算完成。在基础模板里关联一次，以后每天都会自动带上。示例里的「背单词」「学编程」「读书」已经关联好，可以直接试。
- **备份**：导出 / 导入 JSON 备份文件。
- **一句话改日程（AI）**：日程上方的输入栏可以打字，也可以点 🎤 说话（Chrome / Edge 自带语音识别），比如「下午三点到五点加个组会」「今晚不去散步了，改成复习一小时」「耽误了40分钟，后面都顺延」。
  - **分工**：大模型只负责把这句话翻译成操作指令（新增 / 挪动 / 改时长 / 删除 / 顺延 / 重排）；时间怎么排由固定规则决定：已开始、已完成的和睡觉时间不动，空档先吸收顺延，放不下时先压缩运动、护理，再压缩学习，最后才移出重要性低的。
  - **先预览再写入**：每次都会列出「新增 / 调整 / 压缩 / 移出」的清单，确认后才改；改完 7 秒内可以撤销。
  - **⟳ 没做完的往后排**：今天之前没打勾的学习、工作，自动补到现在之后，后面的安排按同样的规则让位。
  - **理解方式**：配置了 `AI_ENDPOINT` 用 DeepSeek；在 Claude 里打开用 Claude；都没有时用本地规则理解常见说法，所以演示时不会因为网络问题失败。模型返回的指令会先校验（活动必须真实存在、时间格式正确），不合格就改用本地规则。

## 接入 DeepSeek（可选）

网页是纯静态的，API Key 不能写在前端，所以用 `worker/worker.js` 做一个 Cloudflare Worker 中转：

1. 在 Cloudflare 后台新建一个 Worker，把 `worker/worker.js` 的内容粘贴进去并部署。
2. 在 Worker 的 Settings → Variables 里添加：`DEEPSEEK_API_KEY`（Secret，填你的 DeepSeek Key）和 `ALLOWED_ORIGINS`（例如 `https://sihan3333.github.io,http://localhost:8000`）。
3. 把 Worker 的地址填到 `index.html` 里的 `var AI_ENDPOINT = '';`，提交并推送。

## 隐私说明

- 所有数据只保存在当前浏览器的 localStorage 里，不会上传到任何服务器，不使用统计分析。
- 页面只从 Google Fonts 加载字体。只有配置了 `AI_ENDPOINT` 并使用「一句话改日程」时，才会把这句话和当天的日程发给自己部署的中转服务（再转给 DeepSeek）。语音识别使用浏览器自带的服务。

## 运行方式

整个应用就是一个 `index.html`，直接用浏览器打开即可；也可以在项目目录下启动静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 重置

修改只保存在当前浏览器中。想回到示例数据，清除本站的浏览器数据即可。
