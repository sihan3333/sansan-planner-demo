# 三三作息簿 · 公开演示

一个用时间轴来安排每一天的作息簿：每天按基础模板自动生成日程，再按当天情况微调，并跟踪学习项目的进度。

在线体验：<https://sihan3333.github.io/sansan-planner-demo/>

> 本仓库是公开演示版。界面和功能与作者自用的最新版一致，但内置的模板、学习项目都是**虚构示例**，与作者本人的生活安排无关。

## 功能

- **今天的日程**：24 小时时间轴，按分类着色；可以前后翻日期、跳到某一天，红线标出当前时间。
  - 支持「时间段」和「时间点」两种活动（比如「出门」就是一个时间点）。
  - 大块活动可以再拆「细分安排」，每一项都能单独打勾。
  - 睡眠时段自动折叠成一条，连续 1 小时以上没有安排的地方标为「空闲」。
  - 时间重叠的活动会用虚线框和 ⚠ 提醒。
- **今日学习**：汇总当天所有学习类活动的完成情况；填了相同「所属大类」的活动（比如「背单词」和「英语听力」都属于「英语」）会合并统计、颜色一致。当天学习全部完成时会放烟花庆祝。
- **基础模板**：编辑一套标准的一天，以后新打开的日期会按模板生成；也可以用模板一键覆盖某一天（会二次确认）。
- **学习项目**：给课程、书、单词等设总量和每日目标，查看进度条和预计还要几天；按大类分组，可以置顶最关心的大类。
- **打勾自动推进度**：日程里的活动可以关联一个学习项目，并设定“完成一次推进多少”。打勾完成后进度自动增加，取消打勾自动扣回；有细分的活动要全部勾完才算完成。在基础模板里关联一次，以后每天都会自动带上。示例里的「背单词」「学编程」「读书」已经关联好，可以直接试。
- **备份**：导出 / 导入 JSON 备份文件。
- **一句话改日程（AI）**：日程上方的输入栏可以打字，也可以点 🎤 说话（Chrome / Edge 自带语音识别），比如「下午三点到五点加个组会」「今晚不去散步了，改成复习一小时」「耽误了40分钟，后面都顺延」。
  - **分工**：大模型只负责把这句话翻译成操作指令（新增 / 挪动 / 改时长 / 删除 / 顺延 / 重排）；时间怎么排由固定规则决定：已开始、已完成的和睡觉时间不动，空档先吸收顺延，放不下时先压缩运动、护理，再压缩学习，最后才移出重要性低的。
  - **先预览再写入**：每次都会列出「新增 / 调整 / 压缩 / 移出」的清单，确认后才改；改完 7 秒内可以撤销。
  - **⟳ 没做完的往后排**：今天之前没打勾的学习、工作，自动补到现在之后，后面的安排按同样的规则让位。
  - **一个入口管三件事**：三个页面共用这个输入栏。AI 判断这句话是改今天、改基础模板（「以后每天早上加20分钟冥想」），还是学习项目（「12月20号前学完机器学习课，一共113集」「今天看了3集编程课」「小说读到150页」「编程课截止推迟到11月20号」）；说不清时按当前页面处理。一句话里混合几件事也可以，预览里会标出每一项改的是哪里。
  - **每天目标由规则算**：建项目时说了截止日期，每天目标 = 剩余量 ÷ 剩余天数（向上取整），模型不参与计算。
  - **理解方式**：配置了 `AI_ENDPOINT` 用 DeepSeek；在 Claude 里打开用 Claude；都没有时用本地规则理解常见说法，所以演示时不会因为网络问题失败。模型返回的指令会先校验（活动必须真实存在、时间格式正确），不合格就改用本地规则。

- **发现了几件事（主动建议）**：不用用户自己去找该改什么，系统用规则统计后主动提出，用户一键采纳或忽略（忽略后 7 天内不再提）：
  - **落后提醒**：学习项目照现在的每天目标，到截止日完不成时提醒，并给出两个选项：提高每天目标，或推迟截止日期（都按剩余量算好）。
  - **根据修改历史建议更新模板**：统计最近两周的日程，某项活动一半以上的日子都被删掉、都被挪到差不多的时间，或者某项活动经常被临时加上，就建议把模板也改过来；采纳后同样先预览再写入。
- **示例数据**：第一次打开时会生成 10 天虚构的历史日程（比如散步经常被删、英语听力常挪到 19:00），并让示例学习项目有一个稍微落后，方便直接看到上面两种建议。「备份」里的「恢复示例数据」可以随时重来。

## 数据后端与看板（backend/）

用 FastAPI + SQLite 记录使用事件，并汇总成数据看板，回答两个问题：**AI 改日程理解得准不准**、**计划能不能落地**。

- **记录的事件**：AI 请求（原话、理解方式、耗时）、方案展示 / 采纳 / 取消 / 撤销、采纳后 5 分钟内的手动修改、打勾完成，以及每天日程的最新状态。
- **核心指标**：「一次就对」的比例（采纳了，而且没撤销、没再手动改）、方案采纳率、撤销率、应用后手动修改率、没听懂的比例、大模型理解占比和回退率；按分类和时段的完成率；最常完不成的活动。
- **待复盘样本**：被取消、被撤销、没听懂、采纳后又手动改的原话列表，用来归类错误、迭代提示词和规则，并作为回归测试集。
- **隐私**：只用随机生成的匿名 ID，不记录身份信息；发送失败或后端没开都不影响使用。目前只在本地（`localhost`）打开作息簿时才会发送。

本地运行：

```bash
cd backend
pip install -r requirements.txt
uvicorn app:app --port 8001 --reload
```

另开一个终端，在项目根目录运行 `python -m http.server 8000`，然后打开 `http://localhost:8000` 使用作息簿，打开 `http://localhost:8001/dashboard` 查看看板（每 5 秒自动刷新）。

`python seed_demo.py` 会生成 14 天的**模拟数据**（匿名 ID 以 `sim-` 开头），只用于展示看板效果。看板默认不计入模拟数据，勾选「包含模拟数据」才显示，并带「模拟」标记；`python seed_demo.py --clear` 可以清除。

## 指令解析评测（eval/）

衡量「一句话」被理解得准不准：用一份固定的日程、模板和学习项目（当前时间 14:00），把每句话分别交给 DeepSeek 和本地规则解析，和标准答案逐条对比。

- **判分**：一句话产生的指令必须**全部对上**才算对——类型、对象、时间或数量、改今天还是改模板都要一致，不能多也不能少。对有歧义的说法（比如「两周内」算 13 天还是 14 天），标准答案里列出所有合理答案。
- **错误归类**：没解析出指令、无关的话被执行、漏掉指令、多出指令、找错对象、改错位置（今天/模板）、名称不对、时间或数量不对。
- **用例**：两套，评测页顶部切换。`eval/cases.json` 是开发者编写的 60 条种子用例；`eval/cases_user.json` 是 10 位同学写的 100 条真实说法（各自带一份更贴近学生日常的固定场景）。超出产品能力的说法，标准答案是「不做任何修改」，和能力范围内的句子分开统计。
- **报告**：种子集见 `eval/REPORT.md`，真实说法见 `eval/REPORT_user.md`（89% 的真实说法超出单日时间轴的能力；超出能力时 DeepSeek 原本有 40% 会把请求套到今天或模板上，在规则层加日期检查后降到 17%）。
- **日期检查**：说法里提到明天、周几、下周、昨天等其他日子时，不执行日程修改，并提示暂不支持；学习项目的截止日不受影响。

运行：在项目根目录 `python -m http.server 8000`，打开 `http://localhost:8000/eval/`，点「两种都跑」。DeepSeek 需要已部署 `worker/` 中转，且 `ALLOWED_ORIGINS` 包含 `http://localhost:8000`。

**注意**：种子用例和本地规则出自同一个人，本地规则在种子用例上的分数偏高；对外引用的准确率应基于真实用户说法。针对失败样本修改提示词或规则后，要在新的一批说法上复测，避免只是「背答案」。

## 接入 DeepSeek（可选）

网页是纯静态的，API Key 不能写在前端，所以用 `worker/worker.js` 做一个 Cloudflare Worker 中转：

1. 在 Cloudflare 后台新建一个 Worker，把 `worker/worker.js` 的内容粘贴进去并部署。
2. 在 Worker 的 Settings → Variables 里添加：`DEEPSEEK_API_KEY`（Secret，填你的 DeepSeek Key）和 `ALLOWED_ORIGINS`（例如 `https://sihan3333.github.io,http://localhost:8000`）。
3. 把 Worker 的地址填到 `index.html` 里的 `var AI_ENDPOINT = '';`，提交并推送。

## 隐私说明

- 所有数据只保存在当前浏览器的 localStorage 里，不会上传到任何服务器，不使用统计分析。
- 页面只从 Google Fonts 加载字体。只有配置了 `AI_ENDPOINT` 并使用「一句话改日程」时，才会把这句话和当天的日程发给自己部署的中转服务（再转给 DeepSeek）。语音识别使用浏览器自带的服务。在本地打开时，使用事件会发送到本机的数据后端（见上文），不会发到其他地方。

## 运行方式

整个应用就是一个 `index.html`，直接用浏览器打开即可；也可以在项目目录下启动静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 重置

修改只保存在当前浏览器中。想回到示例数据，清除本站的浏览器数据即可。
