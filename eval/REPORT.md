# 指令解析评测报告 · 种子集

## 设置

- **用例**：60 条种子用例（`author: seed`），覆盖 14 类指令：新增（具体时间 / 只说时长）、删除、挪动、改时长、顺延、重排、多个指令、改模板、新建项目、记进度、改项目、删除项目、无关的话。
- **固定场景**：一天的日程（当前时间 14:00，上午的活动大多已完成，「背单词」没做）、基础模板、4 个学习项目。
- **对比对象**：DeepSeek（经 Cloudflare Worker 中转，temperature 0）与本地规则（正则 + 关键词）。两者的输出都先经过同一套校验（对象必须真实存在、时间格式正确）。
- **判分**：一句话产生的指令必须全部对上才算对，不能多也不能少。有歧义的说法接受所有合理答案，例如「两周内读完」的截止日按 13 天或 14 天都算对，「100道SQL题」的单位写成「题」或「道」都算对。

## 失败分析

**DeepSeek（1 条）**

- #18「数据分析改到晚饭后」→ 挪到 18:00（晚饭开始），标准答案是 19:00（晚饭结束）：参照物理解成了开始而不是结束。

**本地规则（10 条），按原因归类**

| 原因 | 用例 | 说明 |
|---|---|---|
| 不支持参照物 | #18、#21「晚饭后」 | 规则只认具体时间，不会去查「晚饭」几点结束 |
| 上下午推断 | #19「提前到七点」 | 没说上下午的 7 点被当成早上 7 点；规则把 1–6 点默认成下午 |
| 一句话里重复说时长 | #2「…大概半小时」、#4「…，一个小时」 | 逗号后的时长被拆成第二条「新增」 |
| 说法没覆盖 | #22「只读半小时」、#42「100道」、#43「新建一个学习项目：…」、#54「总共其实是120集」、#56「项目删了吧」 | 关键词或单位不在规则里 |

本地规则用于没有网络时兜底，日常理解由 DeepSeek 完成。
